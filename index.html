About This Project

Project Title
Web Technologies & Applications — Individual Project
Student Name
DJENKEU EDOU Livyo Kurtys
Description
A four-milestone individual project that progressively builds a complete single-page application (SPA) for searching and displaying book information from the Google Books public API. Each milestone adds a new layer of functionality, starting with static JSON data display and culminating in a fully interactive, AJAX-driven web application.
